Zero-hallucination policy — No Hallucinations Commitment

No hallucinations: every price, purity claim, weight and policy on this site is copied from a named official source page and stamped with the date it was read. If a source does not publish a value, the value is left blank and marked unverified — it is never estimated, inferred, or filled in to make a row look complete. Recommendation: actively look for hallucinations by clicking the official source link on every row, re-checking live prices and weights before buying, and running our automated anti-hallucination security checks after every review pass.

Run the checks yourself

python3 scripts/verify.py && python3 scripts/build_site.py

python3 scripts/audit.py && python3 scripts/report_verify.py

python3 scripts/requirements_matrix.py && python3 scripts/hallucination_scan.py

The first pair gates and builds the site; the second audits the dataset and regenerates the verification report. All four run in CI on every push and pull request.

The standing recommendation

Re-run the audit after every review, then spend one pass doing nothing but hunting hallucinations: take any number on this site and try to find it on the linked page. If it is not there, delete it and mark the field unverified. A blank cell is an honest result; a confident invention is not.
