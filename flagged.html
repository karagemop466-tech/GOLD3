“Solid gold” is not printed on most listingsdatasetOf the live listings, most describe the metal only as “14K white gold” / “14kt yellow gold”. Under 16 CFR § 23.3 that is a legal karat claim, but it is not the same as saying the ring is solid. This site marks those as “not stated” rather than upgrading them to solid.open ↗
Gram weight is the missing numberdatasetThe checklist asks for the ring's weight in grams. Most major sellers do not publish it, so the gold value of the ring cannot be checked before purchase. This is the largest open gap in the dataset and the first thing to ask a seller by email — the answer should be in writing.open ↗

4. Open items

While reviewing, use the hallucination watchlist — it lists the eight traps this dataset was built to catch (cached prices, from-prices, setting prices, plating karats, invented weights, dead listings, stamps treated as proof, silent contradictions).

  • Ask each seller for the ring's gram weight in writing, then add it to the dataset with the seller's reply as the source.
  • Read and quote the full return policy for Blue Nile, James Allen, Ross-Simons and Catbird (currently only the product-page wording is recorded).
  • Independent reputation research per seller (review aggregation, complaint history, registered business address).
  • Add a second spot-price source so the melt value can be cross-checked, not just dated.

GOLD3 — an independent, source-linked buying file for solid gold engagement rings. Every price on this site was read from the seller's own product page on the date shown; where a value could not be confirmed it is left blank and listed on the Flagged for review page.

This site is research, not legal, financial or appraisal advice. A karat stamp is a claim, not a test. Have any ring verified by an independent jeweller before wearing or resizing it.
