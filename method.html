How this was built

Method & audit

The whole value of this project is that you can check it. This page explains exactly where each number came from, what was deliberately left out, and what the automated anti-hallucination audit verifies after every review pass.

The no-hallucination protocol

  1. One source of truth per value. A price, karat, colour or weight may only exist in the dataset with a quoted string taken from the seller's own page, plus the date the page was read.
  2. Live beats cached. A value seen in a search-engine copy of a page is recorded as an observation but is never used as the price. Only a page opened and read counts as a live check.
  3. Blank beats wrong. If the page does not publish it, the field stays null. The site shows — and the entry appears on Flagged for review.
  4. Wording must match the verdict. “Solid gold = yes” is only allowed if the quote contains the word solid; “solid gold = no” only if the quote contains plating/vermeil/filled/overlay wording.
  5. Arithmetic must reproduce. Every melt value is recomputed from stored inputs with the published formula, and any price below its own melt value is flagged, not published as a deal.
  6. Conflicts are surfaced. Two prices for the same URL are both stored, and the disagreement is flagged.
  7. Links must sit on their own domain. Every stored URL is checked against the domain it claims to belong to, so a guessed or copy-pasted link cannot pass as evidence. Unverified placeholder URLs were deleted, not kept.

Formulas

fine_g= ring weight in grams × karat ÷ 24
spot_per_g= spot price per troy ounce ÷ 31.1034768
melt_value= fine_g × spot_per_g
premium= (price − melt_value) ÷ melt_value × 100 — only when the price covers the whole ring

Spot reference: World Gold Council — Goldhub, Gold spot prices ↗ — $4,024.36/ozt as of 2026-10-21, read 2026-10-22.

Hallucination watchlist — read the list with this in mind

Every one of these traps was actually hit while building this dataset. Check for them before you trust any gold-ring list, including this one.

TrapWhat it looks likeHow this site handles it
Cached priceA search result quotes $270; the live page says $299.Only a page opened and read can set a price. Cached figures are stored as observations and flagged.
"From" price$2,900 that becomes $3,400 once you pick a configuration.Labelled from-price; never compared to melt.
Setting price$1,145 that excludes the centre diamond entirely.Labelled setting only; the melt comparison prints "n/c".
Plating karat"18k gold vermeil" — the 18k is a 2.5-micron coating, not the ring.Recorded as NOT solid; no melt value is computed for a plated piece.
Invented weightEstimating grams from a photo or from "typical" ring weights.Weight is blank unless the seller publishes it. No table row has an estimated weight.
Dead listingA URL that now 404s or redirects, still carrying an old price.Marked dead, price cleared, excluded from the buy list, shown in "Excluded".
Stamp taken as proof"14K" on the band treated as confirmation of purity.Stamps are treated as claims; 15 U.S.C. § 295 tolerances and the independent-testing step are linked on the Rules page.
Silent contradictionA product page saying both "non returnable" and "exchange only".Published on Flagged for review instead of being summarised into a clean-but-wrong answer.

What this project is not

Not an appraisal, not legal advice, not a price guarantee. Prices change without notice — the date on every row is the only thing that makes it honest. Before buying, confirm the price on the seller's page yourself, and before wearing the ring, have an independent jeweller test and weigh it.

GOLD3 — an independent, source-linked buying file for solid gold engagement rings. Every price on this site was read from the seller's own product page on the date shown; where a value could not be confirmed it is left blank and listed on the Flagged for review page.

This site is research, not legal, financial or appraisal advice. A karat stamp is a claim, not a test. Have any ring verified by an independent jeweller before wearing or resizing it.
