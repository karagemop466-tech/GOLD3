No hallucinations — the rule this page enforces

If a number is not on the linked page, it does not belong in the dataset. A value found only on a search result, a cached copy, or a "typical" price list is treated as invented. When a seller does not publish a value, the cell stays blank and carries an unverified badge. Better an empty cell than a confident error.

  • Confirmed — the value was found verbatim on the page on the date shown.
  • Corrected — the value was on the page but the row described it wrongly, so the row was fixed.
  • Flagged — the page contradicts itself, or the listing cannot be safely bought as described.
  • Deleted — the page did not support the claim at all, so the claim was removed rather than softened.

Re-run python3 scripts/audit.py after any change, then repeat the hallucination pass by hand: pick any number on the site and try to find it on the linked page.

How to do that check yourself

Take the ring, before wearing or resizing it, to an independent jeweller — not the seller — and ask for an XRF test or an assay, plus a weight on a calibrated scale. Compare the reading with the karat stamp and with the weight recorded here. Keep the receipt from that test with your order documentation.

If the reading is below the stamp, stop: contact the seller in writing inside the return window and keep the ring unworn.

If a seller will not let you independently verify the ring, or will not let you return it after verification, do not buy it. No price and no brand reputation overrides that rule.
